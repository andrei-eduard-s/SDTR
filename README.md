# SDTR
# Sistem de ventilație adaptiv

Acest proiect constă în dezvoltarea unui sistem adaptiv de ventilație pentru medii industriale sau locuințe personale folosind placa de dezvoltare STM32 NUCLEO-F103RB cu microcontroler Cortex-M3 și debugger integrat. Sistemul ajustează automat fluxul de aer în funcție de temperatura, umiditatea și concentrația de gaze. Funcționarea în timp real asigură un răspuns rapid la orice schimbare pentru a menține condiții optime, iar utilizatorii pot monitoriza și modifica setările printr-o interfață Bluetooth.
